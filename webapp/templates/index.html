Research workflow

How an equity desk uses Kronos — from universe to a written view, before any size decision.

  1. 01

    Screen the universe

    Cut noise with trend, momentum, liquidity, and risk filters. Leave a short list, not a hundred tabs.

    Screener →
  2. 02

    Read the name

    Price path, multi-horizon returns, key stats, consensus, and technical structure on one Stock page.

    Stock view →
  3. 03

    Deep work on the desk

    Compare peers, run Wall Street / financials templates, note the thesis, check options tilt when listed.

    Research Hub →
  4. 04

    Map scenarios

    Near-term path with a high / centre / low band. Treat it as a scenario set for the note—not a target price mandate.

    Forecast →
  5. 05

    Pressure-test vs peers

    Same metrics, same periods: growth, margins, profitability, multiples. Mark where the name leads or lags.

    Peer valuation →
  6. 06

    Watch and write

    Park the name with thesis notes and invalidation. Use the nav strip for daily % without reopening everything.

    Watchlist →
  7. 07

    Validate before size

    Walk-forward / paper checks under past conditions. Research aid only—Kronos does not place orders.

    Backtest & paper →
